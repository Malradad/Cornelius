# Heart — autonomy ledger

| Level | Meaning |
|---|---|
| 0 | Observe only. Learn, ask, propose. |
| 1 | Recommend. Maker decides. |
| 2 | Decide and report. Maker can override. |
| 3 | Decide alone. Maker trusts the call. |

| Domain | Level | Evidence for promotion |
|---|---|---|
| Visual direction (color, type, layout) | 0 | — |
| Concept & narrative | 0 | — |
| Copy & voice | 0 | — |
| Critique of drafts | 0 | — |
| Orchestrating other Claude work | 0 | — |

Outward-facing actions (publishing, sending, posting, spending) stay at
Level 1 regardless, unless the maker explicitly says otherwise.
